# 冰環 / 紅魔散熱器 BLE 協議(逆向自 APK 2.8.91, 包名 com.magcooler.binghuan.v2646)

全部特徵為 16 位 UUID(`0000xxxx-0000-1000-8000-00805f9b34fb`),寫入均為 Write With Response。
裝置識別:名稱含 redmagic / red magic / nubia / magcooler / mag cooler / jacket / srq / 8pro / `rm 8 pro`,
或廣播的服務 UUID 含 1011 / 1015 / 101C / 1019 / 101A。

| UUID | 作用 | 值 |
|---|---|---|
| 1011 | 散熱開關 | 寫 `02`=開 `03`=關;讀/通知 `03`=已關 |
| 1012 | 手動檔位 | 10 檔:`40 44 46 52 58 64 68 72 76 80`(十進位制) |
| 1013 | 燈光 | `[模式,R,G,B]`:1炫彩 2呼吸(多色) 3單色呼吸 4常亮 5關 6電池溫度 |
| 1014 | 散熱器溫度 | 1位元組 int8 ℃;或 `04 t` |
| 1015 | 狀態包(通知) | `04 t` 溫度;`05 7F` 停機/`05 80` 執行;`08 hi lo` 轉速;`09 w` 功率(≤80) |
| 1017 | 破壞神 | `01`/`00`(原版先寫 1012=80 再寫 1017=01,並多次確認) |
| 1018 | 智慧溫控 | `01`/`00`(與破壞神、手動互斥) |
| 1019 / 101C | 轉速 | 大端 16 位 |
| 101A / 101D | 功率 | 1 位元組 |
| 101F | 保護閾值 | `[flag,0,高溫閾值,低溫閾值]` |
| 2A26 / 2A28 | 模組/主控韌體版本 | ASCII |

模式互斥:切到手動時先寫 1018=0、1017=0;原版為防止回包亂序會重複寫入確認,本移植僅對破壞神做了一次補發。
