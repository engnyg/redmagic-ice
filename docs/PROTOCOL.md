# 冰环 / 红魔散热器 BLE 协议(逆向自 APK 2.8.91, 包名 com.magcooler.binghuan.v2646)

全部特征为 16 位 UUID(`0000xxxx-0000-1000-8000-00805f9b34fb`),写入均为 Write With Response。
设备识别:名称含 redmagic / red magic / nubia / magcooler / mag cooler / jacket / srq / 8pro / `rm 8 pro`,
或广播的服务 UUID 含 1011 / 1015 / 101C / 1019 / 101A。

| UUID | 作用 | 值 |
|---|---|---|
| 1011 | 散热开关 | 写 `02`=开 `03`=关;读/通知 `03`=已关 |
| 1012 | 手动档位 | 10 档:`40 44 46 52 58 64 68 72 76 80`(十进制) |
| 1013 | 灯光 | `[模式,R,G,B]`:1炫彩 2呼吸(多色) 3单色呼吸 4常亮 5关 6电池温度 |
| 1014 | 散热器温度 | 1字节 int8 ℃;或 `04 t` |
| 1015 | 状态包(通知) | `04 t` 温度;`05 7F` 停机/`05 80` 运行;`08 hi lo` 转速;`09 w` 功率(≤80) |
| 1017 | 破坏神 | `01`/`00`(原版先写 1012=80 再写 1017=01,并多次确认) |
| 1018 | 智能温控 | `01`/`00`(与破坏神、手动互斥) |
| 1019 / 101C | 转速 | 大端 16 位 |
| 101A / 101D | 功率 | 1 字节 |
| 101F | 保护阈值 | `[flag,0,高温阈值,低温阈值]` |
| 2A26 / 2A28 | 模块/主控固件版本 | ASCII |

模式互斥:切到手动时先写 1018=0、1017=0;原版为防止回包乱序会重复写入确认,本移植仅对破坏神做了一次补发。
